# ⚡ CYBER DODGE

Динамичная и залипательная неоновая аркада с элементами киберпанка, системой аккаунтов, рандомными усилениями, чекпоинтами и магазином улучшений! Написана на чистом HTML5 Canvas + JavaScript (Single-File App).

> **Автор / Разработчик:** mosslurk (2026©)

---

## 🚀 Особенности игры
- **🎮 Удобное управление:** Поддерживается клавиатура (WASD / Стрелки), мышь и сенсорные кнопки на мобильных устройствах.
- **🛡️ Рандомные усиления:** Ловите на поле щиты, слоумо, магниты, призрачный рывок и бонусные очки (`+500`).
- **🚩 Чекпоинты (Сейвпоинты):** Каждые 300 очков на карте появляются флажки, сохраняющие ваш прогресс для возрождения.
- **💾 Система аккаунтов:** Рекорды, баланс монеток и купленные улучшения сохраняются локально (`localStorage`).
- **💎 Магазин улучшений:** Покупайте перманентный щит на 3 минуты, удвоение монет (x2), супер-магнит или стартовый буст.
- **🎨 Кастомизация стилей:** Несколько цветовых тем оформления интерфейса и шарика (Кибер-Неон, Томный Фиолетовый, Кровавый Рубин, Солнечный Золотой).
- **🎶 Атмосферная музыка:** Встроенный Web Audio API генератор мягкого расслабляющего эмбиента.


## 📱 Установка на телефон и ПК
* **На ПК (Windows):** Откройте игру в Chrome/Edge, нажмите три точки сверху → *«Установить страницу как приложение»*.
* **На телефоне (Android/iOS):** Откройте ссылку на игру в браузере смартфона, выберите в меню *«Добавить на главный экран»*. Игра будет работать на весь экран как нативное приложение и без интернета!
